Écrire un contrepoint note contre note

Clique sur la portée du haut pour placer une ronde au-dessus de chaque note du cantus firmus. Clique de nouveau sur une note pour changer son altération (♯, ♭, ♮). Puis vérifie : chaque faute est signalée en rouge, mesure par mesure.

Écrire un contrepoint en blanches (2e espèce)

Place deux blanches par mesure : clique dans la moitié gauche d'une mesure pour le 1er temps, dans la moitié droite pour le temps faible. Les deux dernières mesures prennent une ronde. Les temps forts doivent être consonants ; au temps faible, une dissonance est permise si c'est une note de passage.

Méthode : écris d'abord les temps forts comme en 1re espèce (consonances, pas de 5tes ni d'8ves consécutives), puis relie-les par des notes de passage.
